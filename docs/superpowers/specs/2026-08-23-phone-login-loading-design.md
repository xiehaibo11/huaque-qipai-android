# 手机登录加载遮罩设计

## 目标

用户提交有效手机号和六位验证码后，在真实登录请求完成前显示复用现有光环动画的全屏遮罩，组件文案为“正在登录”。

## 参考与视觉

- 参考 `闲逸斗地主` 的 `util.LoadingView`：加载层位于场景最上层、拦截输入、文案可配置，并由异步请求生命周期控制显示和关闭。
- 复用当前 `XianyiLoadingView`、`xianyi_jiazaiya` 图集、字魂经典力黑和现有 1920x1080 坐标体系。
- 登录遮罩覆盖手机登录弹窗，使用半透明黑色背景；光环组件保持 340x340 并居中，不增加新视觉资源。
- 启动阶段继续显示“加载中”，登录阶段显示“正在登录”。

## 状态与交互

- Lua 登录状态进入 `VERIFYING` 时显示遮罩并禁止重复点击。
- 验证失败进入 `ERROR` 时移除遮罩，保留手机号和验证码，显示原有错误文案并允许重试。
- 验证成功进入 `AUTHENTICATED` 时保持遮罩，直到大厅页面替换登录页面。
- 关闭登录弹窗、Activity 销毁或切换大厅时停止动画回调并移除遮罩。

## 验证

- 单元测试覆盖 `VERIFYING`、失败和成功过渡时的遮罩可见性，以及循环字符动画不会停在 100%。
- 运行完整 Android 单元测试和 Debug APK 构建。
- 在当前模拟器中使用真实生产验证码登录，截图验证遮罩、文案、层级和无重叠。
