# 启动协议弹窗设计

## 目标

南北娱乐 Android 客户端在首次安装、应用数据被清除或协议版本更新后，于登录页出现时展示不可绕过的协议弹窗。视觉以 `UI-skill install/用户协议.psd` 为准，交互参照闲逸斗地主 `ProtocolPrivacyLayer.lua`。

## 行为

- 启动 Logo、品牌页和资源加载流程保持不变。
- 登录页显示后，若本地已同意版本与当前协议版本不同，立即覆盖显示协议弹窗。
- 用户协议和隐私政策分别通过系统浏览器打开后端登录协议接口提供的可信 HTTPS 地址；接口失败时使用官网固定地址。
- 点击“同意”保存当前协议版本、关闭弹窗、勾选登录页协议并允许登录。
- 点击“拒绝”显示二次确认；确认拒绝后退出应用，取消则返回协议弹窗。
- 弹窗显示期间，点击遮罩、登录按钮或系统返回键均不能绕过。
- 后端返回新 `version` 时，即使用户已同意内置版本，也必须重新弹出。

## 视觉

- 从 PSD 导出无文字面板、顶部渐变、标题、拒绝按钮和同意按钮图层。
- 面板在 `1920 × 1080` 虚拟画布中居中，保持 PSD 的 `1549 × 1023` 比例。
- 欢迎语、两条协议链接和拒绝提示使用授权的字魂经典力黑字体原生绘制，颜色、位置和字号按 PSD 对齐。
- 背景增加深色半透明遮罩；弹窗无关闭按钮。

## 状态与数据

- 本地 SharedPreferences 文件：`nanbei_login_agreement`。
- 已同意版本键：`accepted_version`。
- 内置协议版本：`2026-08-23`，与当前登录协议接口一致。
- 接口配置只接受运营方“南北娱乐”和 `www.nanbeiyule.com` HTTPS 链接。

## 验证

- 单元测试覆盖首次启动、同版本、版本升级、默认未勾选和接口版本解析。
- 构建使用生产域名参数。
- 模拟器验证首次弹出、协议跳转、同意后重启不再弹出、清除数据后重新弹出，并截取横屏画面与 PSD 对照。
